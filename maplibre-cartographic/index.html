MMM / SPOTONE 補足資料 - 2026-11-08

背景地図の選び方
OSM ja スタイルをおすすめする理由

左の地図は切り替えながら見られます。説明の「地図に表示」ボタンでも切り替わります。

01

現状の課題

地理院地図(標準)は地図記号・等高線・注記が多く、背景として使うと主役の情報が埋もれる、というのが開発側 2 名の所感です。

淡色地図は配色が淡くなりますが、ラスタ画像なので表示項目は変えられません。

02

おすすめ: OSM ja スタイル 推奨案

OpenStreetMap Foundation Japan が配信している、日本語表記のベクタータイルとスタイルです。Orbital Sense の標準地図と同じ系統で、お送りいただいた画面の見た目と帰属表示(OpenMapTiles / OpenStreetMap contributors)が一致しています。

良い点行政区の境界と道路の種別が見やすい。POI が適度に載っている。
惜しい点旅行アプリでは鉄道がほしい。次の節で補い方を整理。
スタイル
https://tile.openstreetmap.jp/styles/osm-bright-ja/style.json
ライセンス
CC-BY。表記は「©OpenStreetMap Contributors」(OSM Wiki の記載)。

確認が必要な点。コミュニティ運営のサーバーです。本番での利用上限や可用性は、公開情報では確認できていません。Orbital Sense に重ねる場合は、背景をどこから配信するかをブレインパッドと揃えるのが安全です。

03

鉄道の補い方

3 通りの経路があります。

1. OSM から生成する

OSM の鉄道データ(railway=rail など)を Overpass で取り出して GeoJSON として重ねるか、自前のタイルに含めます。データは ODbL です。

2. 国土数値情報の鉄道データ

駅と路線のデータです。OpenPOI のドキュメントでは CC BY 4.0 とされています。取得時に、各データの利用条件を確認してください。

3. OpenRailwayMap を重ねる

鉄道専用の地図です。データは ODbL、タイルは CC-BY-SA 2.0 で、帰属表示が必須です。ボランティア運営で可用性の保証がなく、小規模な利用向けとされています。本番では自前の配信を勧めています(OSM Wiki)。

日本向けに鉄道などを載せたスタイルの例として、MIERUNE が MapTiler Cloud 向けに公開しているものがあります(FOSS4G 2022 の講演より)。

04

POI とランドマーク

OpenPOI API

日本全国の施設 300 万件以上を検索できる API です。認証は不要で、商用利用もできます。検索は /v1/search(キーワード、中心座標と半径、矩形範囲、1〜200 件)です。

  • 出典に「OpenPOI API」を記載し、結果を保存するときは licenses と attributions も保存します。
  • 制約として、位置のずれ、閉業施設の残存、ランドマークは収録されないことが挙げられています。

OSM / Overpass

OSM のデータは ODbL です。「© OpenStreetMap contributors」の表示が必要で、加工したデータベースを公開する場合は同じ ODbL で提供します。商用でも使えます。観光地や史跡は tourism=attraction や historic=* で取れます。

Overpass クエリの例(天神周辺の観光スポット) 
[out:json][timeout:25];
nwr["tourism"="attraction"](33.55,130.35,33.63,130.45);
out center 100;

考察。OpenPOI は店舗・施設、ランドマークは OSM から、という役割分担が考えられます。OpenPOI はランドマークを収録しないとされているため、ランドマーク用途は OpenPOI だけでは足りません。

05

ほかの選択肢

CARTO
Positron / Voyager / Dark Matter。単色系の定番ですが、現在は無料の API キーが必須です(月 500 万タイルリクエストまで、アカウント不要)。キーなしだと透かしが出ます。以前のようにそのまま使えないのはこのためです。
OpenFreeMap
キー不要。Positron は POI を外した淡色スタイルです。可用性の保証はありません。
地理院ベクトル
最適化ベクトルタイルを国土地理院が試験公開しています。出典は「国土地理院最適化ベクトルタイル」。PMTiles 版があり、ファイル配信のタイルは 2023 年度末までに停止予定と README にあります。使うなら PMTiles を自前でホストする形です。

地理院の地物を任意に選んで取り出す実装例として、筆者の MapLibre カタログがあります。

06

自前でデザインする

ベクタータイルのスタイルは JSON なので、Maputnik などのエディタで色・表示項目・ズーム別の出し分けを編集できます。OpenMapTiles スキーマの既存スタイル(Bright、Positron など)を土台にできます。自作したスタイルは、JSON を自分でホストして URL で読み込みます(OpenFreeMap の Quick Start の記載)。

左の「色調」で、スタイルの色を実行時に書き換える例を確認できます。

Mapbox Studio について。作ったスタイルを MapLibre で使えるか、タイルを自分の環境で使ってよいかは、Mapbox 側の規約に依存します。この資料では確認できていないため、使う場合は条件を確認してください。

07

MapLibre GL JS と native

  • BSD-3-Clause のライブラリで、スタイルは Style Specification の JSON です。
  • MapLibre Native(Android / iOS)も同じ仕様を使うので、スタイルとタイルは共有できます。アプリ側のコードは別実装です。機能の対応状況は完全には一致しません。
  • v6(2026 年 7 月)は ESM のみ・WebGL2 必須です。従来の <script src="maplibre-gl.js"> は動きません。
コード: 最小の地図(OSM ja) 
<link rel="stylesheet" href="https://unpkg.com/maplibre-gl@6.17.0/dist/maplibre-gl.css">
<div id="map" style="width:100%;height:400px"></div>
<script type="module">
  import * as maplibregl from 'https://unpkg.com/maplibre-gl@6.17.0/dist/maplibre-gl.mjs';
  const map = new maplibregl.Map({
    container: 'map',
    style: 'https://tile.openstreetmap.jp/styles/osm-bright-ja/style.json',
    center: [130.4017, 33.5903], // [経度, 緯度]
    zoom: 13,
  });
</script>
コード: OpenRailwayMap を重ねる 
map.on('style.load', () => {
  map.addSource('orm', {
    type: 'raster',
    tiles: ['https://tiles.openrailwaymap.org/standard/{z}/{x}/{y}.png'],
    tileSize: 256,
    maxzoom: 19,
    attribution: '<a href="https://www.openrailwaymap.org/">OpenRailwayMap</a> (CC-BY-SA 2.0)',
  });
  map.addLayer({ id: 'orm', type: 'raster', source: 'orm' });
});
コード: 色を実行時に変える 
map.on('style.load', () => {
  for (const layer of map.getStyle().layers) {
    if (layer.type === 'background') {
      map.setPaintProperty(layer.id, 'background-color', '#efe6d2');
    } else if (layer.type === 'fill' && /water/i.test(layer.id)) {
      map.setPaintProperty(layer.id, 'fill-color', '#c9d3c6');
    }
  }
});
コード: native(同じスタイル URL を渡す) 
// iOS (Swift)
MLNMapView(frame: .zero, styleURL: URL(string: "https://tile.openstreetmap.jp/styles/osm-bright-ja/style.json"))

// Android (Kotlin)
mapView.getMapAsync { map ->
    map.setStyle("https://tile.openstreetmap.jp/styles/osm-bright-ja/style.json")
}
